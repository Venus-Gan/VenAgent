# Outcome

在不复用或改造已废弃 `final/` 目录的前提下，建立一个可运行、可测试的 LangChain/LangGraph 最小 Agent Loop，作为后续按需扩展 VenAgent 的新代码基线。

# Scope

- 在新的源码根目录中实现单轮、无工具、无外部基础设施依赖的 Agent Loop。
- 使用 LangGraph 定义最小状态与图执行边界，并以 LangChain 消息/模型抽象承载模型调用。
- 提供确定性的测试替身，使本地测试无需 API 密钥或网络。
- 以 HTTP API 和单页 Web UI 暴露该最小 Loop；页面保留旧项目的核心对话交互（输入、提交、显示回答），但不承诺迁移其高级能力。
- 为后续增加工具、记忆、RAG、持久化和其他服务能力保留清晰的扩展边界，但本变更不实现它们。

# Non-goals

- 不迁移、修改或删除 `final/` 中的任何实现。
- 不实现工具调用、ReAct、多 Agent、记忆、RAG、数据库、鉴权或部署。
- 不复制旧 Web UI 的知识库、工具选择、会话管理或流式执行等高级交互。
- 不要求真实模型凭据，也不连接外部服务。

# Acceptance examples

- 给定一条用户消息和确定性模型替身，Agent Loop 返回该模型生成的助手消息，并保留按角色排列的消息状态。
- 空白或空消息在进入模型前被拒绝，并给出可预期的输入错误。
- 单次调用最多执行一个模型节点；不产生工具调用、网络访问或持久化副作用。
- 自动化测试可在未配置 API Key 的环境中通过。
- 浏览器在提交非空文本后显示由最小 Loop 生成的助手回复；页面提供与旧项目一致的基础聊天布局和输入方式。

# Constraints and invariants

- 新实现与 `final/` 物理隔离；该目录只作为历史参考，不能成为新运行时依赖。
- 采用 Python，并使用 LangChain/LangGraph 的公开稳定接口；依赖版本和项目布局须在实现时明确固定。
- 默认执行路径必须可离线、确定性地验证；真实模型接入只能通过可替换适配器。
- 不将密钥、连接串或其他凭据写入仓库、测试或 Comet 产物。
- Web UI 调用本地 HTTP API；API 的默认模型适配器不得在未配置凭据时访问网络。

# Decisions

- 采用由简至繁的绞杀式重构：本次只交付最小 Agent Loop，后续能力按独立变更逐项加入。
- `final/` 已废弃，因此本次不在其中继续开发，也不将其作为兼容目标。
- 新运行时以 LangChain/LangGraph 为技术基础。
- 首个公共入口为 Web UI 和本地 HTTP API；UI 维持旧项目的核心聊天体验，底层 Loop 也保持可从 Python 调用以便测试和后续复用。

# Open questions

无。

# Verification expectations

- 运行针对最小 Loop 和 HTTP API 的自动化测试，覆盖正常单轮、输入校验与无网络/无凭据运行。
- 通过浏览器或 API 集成测试验证 Web UI 的核心提交与回复展示流程。
- 静态检查项目导入边界，确认新代码不依赖 `final/`。
