# 真实 LLM 适配器

## 目标

VenAgent SHALL 在本机明确配置 OpenAI 兼容聊天服务时，以当前最小 Agent Loop 调用该服务；在配置缺失时继续提供离线本地模型。

## 配置

- 服务地址、密钥和模型 ID SHALL 分别从环境变量或 Git 忽略的 `.env` 中读取。
- 版本控制中的示例配置只能包含变量名和占位值，绝不能包含可用密钥。
- 已确认的模型 ID 为 `gpt-5.6-terra`；它 SHALL 作为 `.env.example` 的示例值，但代码不得把它硬编码为唯一可用模型。

## 运行行为

- 三项真实模型配置均存在时，应用 SHALL 构造 OpenAI 兼容聊天模型并将其注入 Agent Loop。
- 任一项缺失时，应用 SHALL 使用现有本地回显模型并保持 API 和 Web UI 可用。
- 真实模型调用结果仍作为单一助手消息追加到图状态；不得引入工具、记忆、流式或额外图节点。

## 安全边界

- 密钥不得出现在响应体、异常消息、日志、测试、提交文件或工作流摘要中。
- HTTP 层只能调用 Agent Loop，不能绕过该边界直连模型服务。
