# Outcome

确保后续面向用户的说明性文档和审计正文使用中文，同时保持 Comet 机器可读固定标题与归档证据的完整性。

# Scope

- 约束后续生成的说明性文档、审计报告和用户回复使用中文。
- 根据用户确认，可能新增当前 ECC 审计的中文阅读版。

# Non-goals

- 不修改 `venagent/` 后端代码、测试或运行配置。
- 不直接改写已归档的 Native 审计证据。
- 不翻译 Comet 固定机器标题、ID、路径或命令。

# Acceptance examples

- 后续审计标题、范围、发现、影响、修复建议和验证结论均使用中文。
- 机器要求的固定标题仍保持原格式，以保证 Runtime 可验证。
- 若生成当前审计中文阅读版，内容与归档审计的事实和严重度一致。

# Constraints and invariants

- 已归档 evidence 保持不可变。
- 仅使用中文叙述，不翻译代码标识、文件路径、命令和协议字段。

# Decisions

- 用户要求后续回答与生成的说明性文档使用中文。
- 用户选择不改写既有归档审计；中文约束只适用于今后新生成的文档。
- 用户于 2026-07-25 确认完整语言约束。

# Open questions

无。

# Verification expectations

- 检查新生成或更新的说明性正文为中文。
- 若新增中文阅读版，逐项比对其 finding 数量、严重度、路径和验证结果与归档审计一致。
