# 聊天负载边界

## 结果

当前 VenAgent 运行时对单条聊天输入和单次流式输出施加明确的 UTF-8 字节上限，在输出保护性终止时不保存部分对话，并使 LLM 测试 mapping 与本机配置隔离。

## 必需行为

- 单条聊天消息的 UTF-8 编码长度不得超过 32 KiB；HTTP 与直接运行时调用均执行该限制。
- 单次流式输出的累计 UTF-8 编码长度不得超过 128 KiB。
- 输出将超过上限时，运行被取消，流发送 `output_limit_exceeded` 终止错误，且该轮用户消息和部分回答不写入已提交历史。
- `build_runtime_loop` 接收 `Mapping[str, str]` 时，只使用该 mapping 解析 LLM 设置；本机 YAML、`.env` 和进程环境不得改变该路径的结果。
- 正常完成、客户端取消、模型错误和既有线程清理语义保持不变。
- 当前 `START → agent → END` 图结构和五轮历史窗口保持不变。

## 验证

- 测试输入边界的正常与超限情况。
- 测试流式输出边界、稳定终止错误、run/租约清理和无部分提交。
- 测试传入的 LLM mapping 不受本机配置层污染。
- 测试现有正常流和取消行为不回归。
