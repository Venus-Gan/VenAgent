# ECC 轻量治理约定

## 结果

VenAgent 使用 ECC 支持技术检索、技术选型、代码可读性和结构边界，而不引入完整的重型流程或默认静态工具门禁。

## 必需行为

- Comet Native 仍是唯一项目生命周期状态机。
- Python 实现遵守清晰命名、边界验证、显式错误处理、适度抽象、PEP 8、公共接口类型标注和项目架构边界。
- 项目原生测试是主要验证证据；外部静态或安全扫描工具仅在已安装且与变更风险相关时运行。
- 高风险安全场景仍需要最小权限、输入输出边界、秘密保护与相关测试复核；工具不可用时如实记录，而非虚构通过或阻塞普通变更。
- `search-first` 继续用于模块技术选型和已有能力检索。

## 验证

- `AGENTS.md` 的 ECC 路由明确上述边界。
- 规则不要求安装或运行全套 ECC 扫描工具作为默认完成条件。
