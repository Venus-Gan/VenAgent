# 最小 Agent Loop

## 目标

VenAgent SHALL 提供一个以 LangGraph 编排、以 LangChain 消息与模型抽象驱动的最小单轮 Agent Loop。该能力是新代码基线，不依赖已废弃的 `final/` 目录。

## 运行行为

- Loop 接收一条非空用户消息，并构造仅包含该用户消息的初始状态。
- 图仅包含一个负责调用已注入模型的 Agent 节点；该节点把模型返回的助手消息追加到状态并结束执行。
- 调用结果 SHALL 暴露最终助手消息及消息状态，供后续能力复用。
- 空字符串或仅含空白的输入 SHALL 在调用模型前失败，并返回稳定的输入校验错误。

## 可替换模型边界

- 模型依赖 SHALL 通过可注入的 LangChain 兼容聊天模型或等效协议传入。
- 测试 SHALL 使用确定性本地替身；默认测试路径不得访问网络、读取 API 密钥或启动外部服务。

## 隔离与非功能约束

- 新源码不得导入 `final` 或将其作为运行时依赖。
- 本能力不得实现或触发工具调用、持久化、记忆、RAG、多 Agent 或命令行副作用。
- 单次调用只执行一个模型节点。

## 公共入口

VenAgent SHALL 提供本地 HTTP API 和单页 Web UI：

- HTTP API 接收一条用户文本，并返回最小 Agent Loop 的最终助手文本；空白输入返回稳定的客户端错误，不调用模型。
- Web UI SHALL 提供与旧项目一致的核心聊天交互：消息显示区、文本输入框和提交操作。提交成功后，助手回复显示在消息区。
- 本次 UI 不包含旧项目的知识库、工具选择、会话侧栏、流式步骤或其他高级功能。
- Python 调用边界 SHALL 保持公开可测，HTTP 层不得重复实现 Agent Loop。
