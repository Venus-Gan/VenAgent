## Question

M01–M06 期间对 langchain/langgraph 做过哪些取舍，现在是否仍成立？钉出一组**通用取舍原则**，供所有后续模块票引用（候选，逐条复核）：
- LangGraph 作外层权威状态机；LangChain 只用于单节点内模型调用/结构化输出/工具绑定，不成为整个 Run 的权威循环。
- Prompt 中的能力描述**只是模型引导，不是授权**；任何真实执行必须回 M06 Gateway 重新校验。
- 未绑定 tools 的模型调用若仍返回 tool call，Runtime 以**稳定可观察错误终止**该路径，绝不送进 M06 Gateway（两层工具调用限制=不可绕过的安全不变量）。
- `thread_id=run_id` 只是 adapter 映射，不是业务身份（禁 conversation 复用链）。
- checkpoint 版本不兼容 → incompatible 终态；同一 run 恢复用原 run_id/checkpoint/contract 版本，恢复时重新复核授权与 M06，不信任暂停前 State 的权限。
- 未绑定 tools 只是降低风险措施；ModelDecision 不是执行授权。

## Context

用户：「使用 langchain/langgraph 重构肯定需要依靠它的API，比较有特色的功能我想独立实现」「M01–M06 期间对 langchain/langgraph 做的取舍要重新审视、后续功能实现需要讨论」。凭据：docs/discussions/m06-decisions-draft（『Prompt 中的能力描述只是模型引导，不是授权』；两层工具调用限制）、m07-decisions-draft（不把 LangChain HITL middleware 当 M06 权威；两层工具限制『Runtime 的稳定错误终止才是不可绕过的安全不变量』）、agi-saber-design-reference（六稳定思想 + Adopt/Extend/Compose/Do-not-copy 表）。AGENTS.md 现有「LangChain 与 LangGraph 技术索引」表（含 Codex 能力路径）可在 `docs 重建与 AGENTS/CLAUDE 改造` 中保留并转入新 AGENTS.md。当前实现证据：graph.py 固定单工具闭环（model_decision：>1 工具调用→拒绝置 observation 'multiple_tool_calls_not_supported'；恰 1→stage_tool_call；0→FinalAnswer）、runtime.py 两层限制、JsonPlusSerializer allowlist、checkpoint thread=run 一一对应。

## Resolution

**RESOLVED**（经 grilling 三轮 + 前端可见性补充，用户逐项确认）：

1. **边界**：LangGraph = 外层权威状态机（run/checkpoint/图编排）；LangChain = 仅单节点内模型调用/结构化输出/工具绑定，不成为整个 run 的权威循环。
2. **执行权威**：Prompt 描述/模型产物 ≠ 授权；真实执行一律回 **M06 Gateway** 校验（Operation/Approval/Sandbox）——M06 是唯一执行权威。
3. **【逆转】两层工具调用限制取消**：模型每轮请求都绑 tools、可随时请求工具；未通过 M06 校验的执行请求在 **M06 内**以稳定可观察错误结果拒绝（error/error_code 路径）；Runtime 不再设「未绑 tools」拒路。「稳定错误终止」不变量保留，位置移到 M06 结果层。
4. **过渡**：单回合工具调用数上限暂仍为 1（现状不变）；多调用开放留给 `剩余功能规划`。
5. **run/checkpoint**：thread_id=run_id 只是 adapter 映射非业务身份；同一 run 恢复用原 run_id/checkpoint/contract、重新核授权、不信任暂停前 State；checkpoint 版本不兼容 → incompatible 终态。
6. **图编排方向**：Replanner 事件驱动（节点失败/观察不足/依赖失效/前提改变）+ 完整 Plan revision 而非原地改；M06 执行权威不并入主 Agent 自由循环。
7. **前端（延后）**：工具调用失败前端要可见；涉及 Web 改造，与后续其他修改合并做 → 新建票 `前端工具失败可见性`（blocked by remaining-plan）。

→ 已记入 map「Decisions so far」；作为 ADR 素材交 `docs 重建与 AGENTS/CLAUDE 改造`。
